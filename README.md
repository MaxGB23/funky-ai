# 🧭 Funky AI: Índice y Mapa de Navegación

Bienvenido a la matriz documental de **Funky AI**, el protocolo de Inteligencia Artificial que te permite emular redes asíncronas de agentes (SDD) usando recursos manuales y archivos físicos locales, previniendo la degradación cognitiva de tu IDE.

Como la cantidad de documentos puede abrumar a un nuevo Orquestador, esta es la "Página de Inicio" estricta que indexa dónde está cada bloque de conocimiento.

---

## 🏛️ 1. Teoría y Core del Protocolo
*Documentación central sobre la filosofía. Leer una sola vez.*

- 📄 **[`docs/funky-ai/funky-ai.md`](./docs/funky-ai/funky-ai.md)**
  El **Manifiesto Teórico**. Acá se explican los tres Pilares Fundamentales (Falso Engram, Chats Descartables, Torre de Control) y el concepto de **Tiers Funcionales** (Descompresión Cognitiva para proyectos masivos).

## ⚡ 2. Operatividad y Normativas
*Los manuales prácticos para el labor diario del equipo humano (Router API).*

- 📄 **[`docs/funky-ai/funky-ai-team-guide.md`](./docs/funky-ai/funky-ai-team-guide.md)**
  La **Guía Rápida de Equipo**. Explica el paso a paso transaccional (cómo crear un Worker chat, cuándo matarlo, cuándo usar automatización total vs trabajo manual) dictaminando las **Golden Rules** del proyecto.

- 📄 **[`docs/funky-ai/funky-ai-tutorial-app.md`](./docs/funky-ai/funky-ai-tutorial-app.md)**
  El **Simulador End-to-End**. Un ejemplo real y táctico construyendo un CLI de "Tareas Pendientes", para que el equipo vea cómo es la delegación en la vida real.

## 🧠 3. Configuración y Cerebros de IA
*Archivos a utilizar explícitamente para configurar el IDE y darle memoria a los LLMs.*

- 🤖 **[`docs/prompts/GEMINI-funky.md`](./docs/prompts/GEMINI-funky.md)**
  El **Configurador del Sistema**. Es la base que debés inyectar en configurar tu asistente global (ej: `~/.gemini/GEMINI.md`). Instruye a la IA sobre cómo comportarse, su personalidad, y los protocolos críticos de inicialización de sesión.

- 🛡️ **[`.agents/rules/secops.md`](./.agents/rules/secops.md)**
  El **Engram Global Transversal**. Un ejemplo cristalizado de regla corporativa; obliga a todo Sub-Agente a respetar prácticas DevSecOps (uso estricto de pnpm, sin carets, sin postinstalls) y que se dispara automáticamente cuando hay un `package.json` de por medio.
