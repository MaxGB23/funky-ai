🧠 ¿Qué es Engram?
Memoria persistente para agentes de IA. Un binario en Go, SQLite + FTS5, servidor MCP, HTTP API, CLI y TUI.

Funciona con Claude Code, Cursor, Windsurf, OpenCode, VS Code... cualquier agente que soporte MCP.

La v1.13 que acaba de salir lo lleva un paso más lejos:

→ Engram Cloud en `main` con dashboard web
→ Autosync push/pull real entre agentes y máquinas
→ Audit Log para ver intentos rechazados
→ Obsidian Brain beta: tu memoria de agente como grafo navegable
→ v1.13.1: `engram setup opencode` ahora activa también opencode-subagent-statusline

—

Me la actualicé enseguida y esto es lo que yo hago hoy mismo en mi máquina:

🔗 OpenCode + VS Code/Copilot compartiendo el mismo store local.
Ambos apuntan al mismo engram.db. Si trabajas en la misma máquina, ya comparten recuerdos automáticamente.

El flujo es así de simple:
→ Abres OpenCode
→ Abres VS Code/Copilot
→ Ambos usan el mismo engram.db
→ Un agente guarda con mem_save
→ El otro busca con mem_context o mem_search
→ Comparten memoria. Punto.

Y si quieres mover esa memoria entre entornos o sincronizarla por Git:
→ `engram sync` genera .engram/manifest.json + chunks comprimidos
→ Los versiones, los mueves, los compartes

Esto es lo que pasa cuando una herramienta la construye un crack y la mantiene una comunidad real: cada release abre puertas nuevas.
