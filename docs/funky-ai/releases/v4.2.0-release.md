# 🚀 Funky AI v4.2.0 Release Notes

## 🌟 Resumen de la Versión
MINOR release de **funky skills v2**: el instalador de skills pasó de copiar las bases gentle-ai a ser un **instalador interactivo**. `funky skills` ahora descubre automáticamente las skills en `src/skills/` (por `manifest.js`), permite elegir **todas o un subconjunto** con multiselect (`@clack/prompts`), cancela limpiamente, y copia recursos bin/docs declarados en el manifest de cada skill — no solo el `SKILL.md`.

En paralelo se cerró el **gap de docs v4.1.0**: `sdd-release` ahora inyecta `release-notes.md` desde el template si falta, y `sdd-docs-sync` tiene la regla **doc-nuevo → doc nuevo** (golden + base), que alinea los docs del SSOT con el CLI real. El índice seccional creció a **3 niveles** (`_indice-seccional-template.md` renombrado).

### ✨ Nuevas Funcionalidades y Refactor
- **[Feature] Instalador interactivo (`R-SK-1/6`):** `funky skills` descubre las skills en `src/skills/` y las presenta en un multiselect con opción **"Todas"**, cancelación limpia y selección parcial — ya no copia todo a ciegas.
- **[Feature] Manifest-per-skill (`R-SK-2/3/5`):** cada skill declara en `manifest.js` sus recursos (bin, docs, plantillas); el instalador copia exactamente lo declarado con `executeIntentions` idempotente.
- **[Feature] Índice seccional 3 niveles (`R-SK-7/8`):** `docs-index/template.md` renombrado a `_indice-seccional-template.md` con 3er nivel; `funky scaffold` y `funky skills` mantienen paridad de bytes.
- **[Feature] `sdd-release` inyecta release-notes (`R-SK-10`):** si `release-notes.md` no existe, se inyecta desde `.agents/templates/sdd/release-notes.md` con rutas/versión placeholders.
- **[Feature] Regla doc-nuevo en `sdd-docs-sync` (`R-SK-11`):** comando nuevo → doc nuevo (golden + base actualizadas), con el SSOT como origen.
- **[Docs] Gap v4.1.0 cerrado (`R-SK-12`):** `docs/funky-ai/skills.md` creado y realineado (dest del índice seccional), `docs/repo-map.md` con la fila de `src/skills/` y la fila stale eliminada.

### 🧠 Aprendizajes (Engram)
- **`[manifest-per-skill]`:** El manifest (`manifest.js` por skill) es la fuente única de recursos a instalar; permite descubrimiento y copia selectiva sin hardcodear rutas en el comando.
- **`[multiselect-clack-todas]`:** El patrón `"Todas"` como opción del multiselect de `@clack/prompts` simplifica el "instalar todo" sin perder la selección parcial; cancelar no debe escribir nada.
- **`[regla-doc-nuevo-golden-base]`:** La regla "comando nuevo → doc nuevo" exige actualizar golden Y base en el mismo cambio, con el SSOT como origen — evitando drift entre docs y CLI.
- **`[docs-antes-de-push]`:** Convención del proyecto: los docs sync SIEMPRE van antes del push/release; un PR puede estar merged con la feature pero el release se bloquea hasta alinear docs.
