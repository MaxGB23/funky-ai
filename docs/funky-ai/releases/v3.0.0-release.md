# 🚀 Funky-AI v3.0.0 Release Notes

## 🌟 Resumen de la Versión
Esta es una versión MAJOR (3.0.0) que marca un antes y un después en la arquitectura del framework. Introduce el soporte nativo para los subagentes de Antigravity CLI, permitiendo que el Orquestador delegue trabajo pesado y búsquedas profundas a workers especializados sin contaminar su propia memoria.

### ✨ Nuevas Funcionalidades y Refactor
- **[Feature] Subagentes Nativos:** Soporte completo e integración con Antigravity CLI para `invoke_subagent`. Ahora el orquestador tiene a su "sabueso" para tareas de investigación.
- **[Refactor] Optimización de Memoria:** Implementación de la Regla de Oro para el Memory Polling. Obligando al orquestador a buscar siempre en el Engram antes de gastar tokens en el File System.

### 🛠️ Archivos Modificados
- **`funky-cli/package.json`:** Bump de versión a 3.0.0.
- **`.agents/v3/sdd-orchestrator.md`:** Actualización y protección del protocolo para delegación.
- **`.agents/rules/sdd-orchestrator.md`:** Refinamiento de la Route A.

### 🔒 Guardrails Preservados
- Se respeta al pie de la letra el protocolo post-archive de Git-Ops y la estructura inmutable del Engram.

### 🧠 Aprendizajes (Engram)
- **`[golden-templates-vs-cli]`:** Se consolidó el conocimiento de que los templates del CLI son agnósticos y los del `.agents` son workspace-specific.
- **`[context-pollution]`:** Delegar tareas de exploración pesada a subagentes reduce drásticamente el ruido en el contexto del Orquestador, agilizando la toma de decisiones.
