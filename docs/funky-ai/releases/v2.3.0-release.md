# 🚀 Funky AI v2.3.0 Release Notes

## 🌟 Resumen de la Versión
Esta versión implementa la segunda parte de la feature 015: el **SDD Micro-Planner On-Demand**. 
En la v2.1.0 sentamos las bases de los protocolos, y ahora introducimos el protocolo específico `sdd-micro-planner.md` y un Gate "Human-in-the-loop" en el Orquestador para mitigar la dilución de contexto y las alucinaciones de los workers al enfrentar tareas arquitectónicamente complejas.

### ✨ Nuevas Funcionalidades y Refactor
- **[Feature] Protocolo SDD Micro-Planner:** Nuevo protocolo `sdd-micro-planner.md` para desglosar tareas complejas y generar un `implementation_plan.md` quirúrgico antes del handoff.
- **[Feature] Human-in-the-loop Gate:** El Orquestador ahora frena y pide confirmación humana cuando detecta una tarea con la etiqueta `[⚠️ RIESGO ALTO]`, ahorrando lecturas innecesarias.
- **[Refactor] Simplificación de Templates:** Adelgazamiento del template de `tasks.md` para evitar lecturas de contexto (`index.md`) durante la planificación.

### 🛠️ Archivos Modificados
- **`.agents/protocols/sdd-micro-planner.md`:** Creación del protocolo on-demand.
- **`funky-cli/src/templates/protocols/sdd-micro-planner.md`:** Plantilla base distribuible.
- **`.agents/rules/sdd-orchestrator.md`:** Actualización del Gate de delegación.
- **`.agents/templates/sdd/tasks.md` y `funky-cli/src/templates/sdd/tasks.md`:** Simplificación del prompt inline.
- **`ORCHESTRATOR-STATE.md`:** Bump a v2.3.0.

### 🔒 Guardrails Preservados
- **Context Economy:** Se evita cargar el índice de protocolos en cada sesión.
- **Agent DRY:** El Gate bloqueante reside exclusivamente en las reglas del Orquestador y no en los artefactos editables.
