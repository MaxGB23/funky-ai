# 🚀 Funky AI v4.1.0 Release Notes

## 🌟 Resumen de la Versión
MINOR release del **Movimiento Final de gentle-ai**: la CLI `funky` ahora puede **distribuir las skills del framework gentle-ai a cualquier proyecto** con `funky skills`, y el `--help` de todos los comandos muestra **data viva de los docs del proyecto** en lugar de los defaults genéricos de Commander.

`funky skills` inyecta de forma idempotente las bases de `sdd-release` y `sdd-docs-sync` en `.agents/skills/` del destino y bootstrapa los docs compartidos de SDD (`docs-live-index.md` + índice seccional) con formato canónico — sin sobrescribir goldens personalizadas ya existentes. En paralelo, `funky scaffold` refactorizó la generación de `docs-live-index.md`/`docs-index/` a templates base compartidos con `skills`, garantizando **paridad de bytes** entre ambos comandos.

### ✨ Nuevas Funcionalidades y Refactor
- **[Feature] `funky skills`:** Inyecta las skills base de gentle-ai (`sdd-release`, `sdd-docs-sync`) en `.agents/skills/` del proyecto destino y bootstrapa los docs compartidos de SDD si no existen. Idempotente: no sobrescribe archivos existentes (mismo contrato que `funky scaffold`).
- **[Feature] Bases de skills autoradas:** `sdd-release` y `sdd-docs-sync` distribuidas en `funky-cli/src/templates/gentle/skills/` (golden del repo menos la capa CLI específica del proyecto).
- **[Feature] `--help` enriquecido:** Los comandos top-level muestran data viva del doc del proyecto vía `addHelpText`, con degradación graciosa si el doc falta (no crash, exit 0).
- **[Refactor] Docs compartidos como templates base:** El texto hardcodeado de `docs-live-index.md` en `scaffold.js` se extrajo a `templates/bootstrap/sdd/docs-live-index.md` (placeholder de 1 fila); se definió el **formato canónico del índice seccional** en `templates/bootstrap/sdd/docs-index/template.md`. `scaffold` y `skills` comparten los mismos templates (`add()`).
- **[Docs] `sdd-docs-sync`:** Docs del SSOT realineados con el CLI real (repo-map, scaffold, template-flows con Flujo 4, README) tras la verificación de superficie y comportamiento.

### 🧠 Aprendizajes (Engram)
- **`[templates-como-mecanismo]`:** El template base copiado (no utilidad JS compartida) es el mecanismo de distribución del repo: un solo archivo fuente, cero duplicación entre `scaffold` y `skills`.
- **`[base-vs-golden-delta]`:** La base de gentle-ai = golden MENOS capa CLI (pasos 4a/4b, mención de Commander, ruta bin) y SIN dependencia del SSOT del scaffold; el delta debe fijarse explícitamente al autorar.
- **`[flujo-post-sdd-agents]`:** La convención de sugerir `sdd-docs-sync` → `sdd-release` tras `sdd-archive` vive en el `AGENTS.md` local (no lo sobreescribe ningún sync de gentle-ai).
