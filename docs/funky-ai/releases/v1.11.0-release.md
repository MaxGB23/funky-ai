# 🚀 Funky AI v1.11.0 Release Notes

## 🌟 Resumen de la Versión
Esta versión introduce el protocolo Two-Stage Memory Polling para controlar el costo de tokens del engram a medida que crece. Incluye el índice liviano `docs/engram/index.md` como primera etapa del polling, la separación del Release en Doc-Ops / Git-Ops con hints de modelo, y el enforcement del ciclo de vida `backlog/ → changes/ → archive/`.

### ✨ Nuevas Funcionalidades y Refactor
- **[Feature]:** Two-Stage Memory Polling con índice liviano.
- **[Refactor]:** Separación del proceso de Release en Doc-Ops y Git-Ops con hints de modelos (Pro Low para Orchestrator, etc).
- **[Enforcement]:** Ciclo de vida estricto para features (`backlog/` → `changes/` → `archive/`).
