# 🚀 Funky AI v2.5.0 Release Notes

## 🌟 Resumen de la Versión
Esta versión introduce un cambio arquitectónico crítico en el pilar del "Falso Engram". Hasta ahora, la memoria persistente de los agentes dependía de archivos monolíticos (`discoveries.md`, `bugfixes.md`). A medida que los proyectos escalaban, estos archivos excedían el Context Window, causando "Lost in the Middle" y pérdida de conocimiento clave.

Con **Engram Sharding (Feature 016)**, introducimos una arquitectura distribuida con indexación semántica. Se reemplaza el historial monolítico por fragmentos individuales clasificados por categoría, acompañados del nuevo comando nativo `funky engram add`.

### ✨ Nuevas Funcionalidades y Refactor
- **[Feature] `funky engram add`:** Nuevo comando interactivo y headless para inyectar engramas de manera atómica al sistema. Garantiza el formato correcto y actualiza el índice general sin tener que cargar toda la memoria en un solo archivo.
- **[Refactor] Two-Stage Memory Polling:** El sistema de orquestación fue refactorizado para usar un enfoque de dos etapas. 1) Lectura del `index.md` liviano. 2) Búsqueda profunda `grep_search` en los subdirectorios categóricos (`architecture/`, `pattern/`, `discovery/`, `decision/`, `bugfix/`) según necesidad.
- **[Feature] Tier 3 Workflows (Validado Empíricamente):** Incorporación de custom workflows dedicados (`/funky-propose`, `/funky-spec`, `/funky-design`, `/funky-tasks`, `/funky-apply`) que consolidan el nivel T3 con máximo aislamiento de fases y cero dependencias de subagentes complejos.

### 🛠️ Archivos Modificados
- **`funky-cli/src/commands/init.js`:** Actualizado el bootstrapping inicial para crear el nuevo árbol de directorios del Engram.
- **`funky-cli/src/commands/engram.js`:** Implementación del comando de inyección atómica utilizando `commander` y `@inquirer/prompts`.
- **`.agents/rules/*` y `.agents/templates/*`:** Actualizados los prompts del sistema y reglas SDD para instruir a los agentes a usar la nueva estructura sharded y el comando CLI en vez de sobrescribir archivos Markdown masivos.
- **`docs/funky-ai/*`:** Actualización exhaustiva de toda la documentación operativa, flujos y escenarios de uso.

### 🔒 Guardrails Preservados
- **Safe-Contexting:** Se mantiene la restricción estricta de no cargar directorios enteros, forzando a los agentes a usar `grep_search`.
- **Idempotencia:** `funky engram add` protege el índice de tags duplicados y maneja gracefully las precondiciones del disco.

### 🧠 Aprendizajes (Engram)
- **`[tier3-workflow-isolation]`:** El uso de workflows dedicados por fase para features de complejidad media produce resultados superiores al Tier 3 inline, resolviendo context pollution sin la sobrecarga del Tier 4.
