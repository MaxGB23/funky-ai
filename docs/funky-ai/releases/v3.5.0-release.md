# 🚀 Funky AI v3.5.0 Release Notes

## 🌟 Resumen de la Versión
Mega release de la suite **funky-forge**: pipeline de integración completo, comandos de arquitectura y pricing renovados, y un ecosistema de scaffolding consolidado. El CLI deja de ser un scaffold de un solo comando para convertirse en un pipeline de trabajo completo (`init → scaffold → assess → estimate → pipeline`) con contexto compartido entre fases.

El nuevo orquestador `funky pipeline` coordina las etapas de planeación usando un módulo `context.json` compartido, mientras que `funky assess` y `funky estimate` fueron reescritos como facilitadores de sesión humana+IA con guías de discusión en lugar de templates adversariales. El scaffolding (`funky scaffold`) queda como comando independiente e idempotente.

### ✨ Nuevas Funcionalidades y Refactor
- **[Feature] `funky pipeline`:** Nuevo orquestador de integración con 4 subcomandos: `assess`, `estimate`, `all` y `status`. Coordina las etapas y usa `context.json` compartido.
- **[Feature] `funky scaffold`:** Comando independiente (migrado de `--bootstrap`) que instala el ecosistema agéntico completo (reglas, templates SDD, docs). Idempotente: saltea archivos existentes.
- **[Feature] `funky assess` reescrito:** Guía de discusión arquitectónica de 6 fases (reemplaza el template adversarial), descubrimiento de canvases, flag `--context` para integrarse al pipeline, exit 1 con challenges críticos.
- **[Feature] `funky estimate` reescrito:** Facilitador de sesión de pricing con banner de IA, flag `--context`, extracción de lógica a módulos compartidos.
- **[Feature] `funky init` con canvases estáticos:** PROJECT-CANVAS, INFRA-CANVAS y canvas-planning-guide generados desde templates (adiós generación por código).
- **[Feature] Módulo `context.json`:** Estado compartido entre assess/estimate/pipeline.
- **[Refactor] Comandos obsoletos eliminados:** `phase`, `gentle` y `release`.
- **[Fix] Guards de escritura:** `existsSync` antes de `writeFileSync` en assess/estimate/engram; mensaje amigable para EACCES en vez del error crudo de Node.
- **[Fix] Versión del CLI desde `package.json`:** `funky --version` deja de estar hardcodeado.
- **[Docs] Ecosistema de documentación renovado:** Docs reorganizados (funky-ai vs funky-forge), índice de docs vivos (`docs-live-index.md`), 14 índices seccionales sincronizados, README reframed como CLI multipropósito.
- **[QA] Smoke test v3.5.0:** Guía manual end-to-end (`openspec/archive/smoke-test-v3-5-0/smoke-test-v3-5-0.md`) para validar los 5 comandos antes/después del release.
- **[Meta] Tier 3 renombrado a "Insano 👻"** en reglas y documentación.

- **`openspec/archive/smoke-test-v3-5-0/smoke-test-v3-5-0.md`:** Guía manual de validación end-to-end.

### 🔒 Guardrails Preservados
- Suite de tests en verde (120+ tests vitest).
- Requisitos Node 20.12+ y pnpm.
- Los comandos heredados del framework agéntico (`scaffold`, `feature`, `engram add`) siguen funcionando con el mismo contrato.
- El flujo SDD (Tiers 1/2/3) se preserva; el Tier 3 pasa a llamarse "Insano 👻".

### 🧠 Aprendizajes (Engram)
- **`[version-from-package-json]`:** `funky --version` debe leer la versión desde `package.json`; hardcodearla provoca drift entre el CLI y los documentos de release.
- **`[idempotent-scaffold]`:** Un scaffold idempotente (saltear archivos existentes) es más seguro que sobrescribir, pero requiere guards `existsSync` consistentes en todos los comandos que escriben archivos.
