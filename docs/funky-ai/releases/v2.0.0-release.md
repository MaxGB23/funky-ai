# 🚀 Funky AI v2.0.0 Release Notes

## 🌟 Resumen de la Versión
Esta versión introduce la **Arquitectura de 3 Capas**, un rediseño monumental del sistema de configuración para resolver la sobrecarga de tokens (Context Dilution). Ahora el conocimiento del Orquestador y de los Workers vive en flujos on-demand ("Workflows Antigravity"), garantizando precisión quirúrgica.

### ✨ Nuevas Funcionalidades y Refactor
- **Arquitectura On-Demand (Capa 3):** Creación de `/funky-orchestrator` y `/funky-worker` como workflows específicos que se inyectan dinámicamente.
- **Limpieza Global (Capa 1):** El archivo global ahora solo contiene personalidad, tono y filosofía.
- **Workspace Rules (Capa 2):** Extracción de reglas core del orquestador a `orchestrator-core.md` para reducir carga cognitiva.

### 🛠️ Archivos Modificados
- **`docs/prompts/GEMINI-funky-global.md`:** Eliminada lógica operativa.
- **`.agents/rules/orchestrator-core.md`:** Creado con las reglas estructurales.
- **`.agents/rules/sdd-orchestrator.md`:** Lógica temporal adaptada para migración futura.
- **`funky-cli/package.json`:** Bump a v2.0.0.
- **`README.md`:** Actualización a la versión 2.0.0 y descripción de la nueva arquitectura.

### 🔒 Guardrails Preservados
- La estricta separación entre Orquestador (planificación) y Worker (ejecución) se mantiene intacta, pero ahora respaldada por una separación física de Workflows en lugar de prompts acumulativos.

### 🧠 Aprendizajes (Engram)
- **`[orchestrator-context-overload]`:** Fragmentar contextos de planificación y ejecución reduce drásticamente las alucinaciones y el costo de inferencia (Token Diet).
