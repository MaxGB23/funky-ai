# 🚀 funky-ai v4.8.0 Release Notes

## 🌟 Resumen de la Versión
Esta versión refactoriza el framework SDD por dentro: la delegación de exploración (Route A) migra a un subagente dedicado `flash_lite` con MCP codegraph, las restricciones de trabajo dejan de estar hardcodeadas y pasan a ser datos (`.agents/rules/metodologias.md`), y Tier 2 gana su contrato Apply (`t2-apply.md`) con slots unificados en todos los contratos de delegación.

El orquestador ahora inyecta un bloque `Contexto Previo` pasivo en cada delegación — los workers ya no conocen funkygram ni engram — y los routers T1/T2/T3 quedan alineados (gates 🔴, preflight, escalation matrix). En paralelo, la modernización de tests elimina ~150 aserciones frágiles de copy (snapshots/golden/tokens + gate `FRAGILE_DEBT`) y se aplica RFC 014 (resolución de dominio y rename a `spec.template.md`).

### ✨ Nuevas Funcionalidades y Refactor
- **[Route A — Sabueso]:** subagente de exploración con flash_lite + MCP codegraph; reglas JIT `sabueso-route-a.md` y `codegraph.md` (policy-only).
- **[Metodologías data-driven]:** archivo editable reemplaza la REGLA GLOBAL de strict TDD; el orquestador cachea e inyecta como `Contexto Previo`.
- **[Contrato t2-apply]:** nueva fase Apply delegable en Tier 2; `scaffold.js` registra las nuevas fuentes (27 reglas) con tests.
- **[Custom workflows T3]:** `funky sdd install` inyecta 9 prompts en `docs/funky-ai/prompts/sdd/`.
- **[Contexto Previo pasivo]:** digest redactado por el orquestador; workers desacoplados de funkygram.
- **[Harness modelo-por-fase]:** `.agents/harnesses/modelo-por-fase.md`.
- **[Modernización de tests]:** migración anti-brittle en ~10 suites, coverage v8, gate de deuda frágil.
- **[RFC 014]:** dominio resuelto desde paths de specs y FULL Spec handling en T2/T3.

### 🛠️ Archivos Modificados
- **`funky-cli/src/commands/scaffold.js`:** registro de nuevas fuentes de inyección (reglas + custom-workflows).
- **`.agents/rules/**` (+ mirrors):** metodologias, codegraph, sabueso-route-a, t2-apply, routers alineados.
- **`AGENTS.md`:** contrato de alcance por lote — delegar tras commitear pasando `origin/main..HEAD` (caso canónico: docs-sync).
- **`docs/funky-ai/sdd.md`, `conceptos/*`, `repo-map.md`:** SSOT sincronizada contra el CLI real.

### 🔒 Guardrails Preservados
- Suite completa verde: 36 archivos / 411 tests.
- Slots `## Contexto Previo` presentes en todos los contratos tier2 y workflows.

### 🧠 Aprendizajes (Engram)
- **`mirrors-diverge-intentionally`:** los templates son scaffolds genéricos para proyectos nuevos; las instancias locales se especializan — la igualdad byte a byte no es el objetivo.
- **`docs-sync-delegado`:** los diffs del lote sirven para scoping y atribución, pero el ancla de verdad es siempre el estado actual del código.
