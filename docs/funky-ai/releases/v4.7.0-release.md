# 🚀 funky-ai v4.7.0 Release Notes

## 🌟 Resumen de la Versión
Esta versión introduce una reestructuración profunda en las fases de canvas, assess y estimate para mejorar la precisión y la experiencia de desarrollo (DX). El comando `assess` asume ahora un rol definitivo como juez arquitectónico, mientras que `canvas` se posiciona como un recolector pasivo de requerimientos. 

Además, se ha mejorado el comando `estimate` sumándole manejo avanzado de topicos, señales de severidad y nuevas reglas de interacción multiplicativa, garantizando estimaciones más confiables y una documentación más robusta sin fricciones.

### ✨ Nuevas Funcionalidades y Refactor
- **[Refactor Canvas]:** Se refactoriza el prompt de canvas para ser un recolector pasivo de requerimientos.
- **[Refactor Assess]:** El prompt ahora es el juez arquitectónico definitivo, validado contra 4 ejes arquitectónicos. Se eliminó el uso de `architecture-review.md`.
- **[Feature Estimate]:** Refactor de flag topics con señales de severidad, nuevos rangos de buffers y reglas de interacción. Mejorada la DX del flag `--pricing-team` con advertencias en CLI y fallbacks de plantillas.
- **[Testing]:** Se agregaron tests de dominio e integración para asegurar la resiliencia del refactor de estimate.

### 🛠️ Archivos Modificados
- **`funky-cli/src/commands/estimate.js`:** Mejoras en DX y lógica de CLI.
- **`funky-cli/src/templates/assess/assess-prompt-template.md`:** Refactor del prompt arquitectónico.
- **`docs/funky-forge/assess.md`:** Actualización de la documentación, removiendo referencias obsoletas a architecture-review.md.

### 🔒 Guardrails Preservados
- Contrato de feedback idempotente en la inyección de guías y reportes.

### 🧠 Aprendizajes (Engram)
