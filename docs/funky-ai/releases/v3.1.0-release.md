# 🚀 Funky AI v3.1.0 Release Notes

## 🌟 Resumen de la Versión
Esta versión extiende el sistema de Engram con dos nuevas categorías semánticas: `session` y `release`. Anteriormente, el Orquestador no tenía un destino adecuado para registrar resúmenes de sesiones de trabajo o cierres de features, lo que forzaba a meter ese tipo de contexto bajo `architecture` de forma forzada.

Con `session`, el Orquestador puede guardar lo que se hizo en cada sesión de trabajo como memoria estructurada. Con `release`, quedan disponibles notas de lanzamiento indexadas directamente en el Engram.

El cambio es aditivo y backwards-compatible: todas las categorías anteriores (`architecture`, `pattern`, `discovery`, `decision`, `bugfix`) se preservan íntegramente.

### ✨ Nuevas Funcionalidades y Refactor
- **[Feature] Categoría `session`:** Nueva categoría para guardar resúmenes y aprendizajes de sesiones de trabajo del Orquestador.
- **[Feature] Categoría `release`:** Nueva categoría para registrar notas de lanzamiento en el índice del Engram.
- **[Bugfix] Validación de categorías inválidas:** QA detectó y corrigió inline la ausencia de un guard para categorías desconocidas en el CLI.

### 🛠️ Archivos Modificados
- **`.agents/rules/engram-protocol.md`:** Taxonomía de categorías actualizada con `session` y `release`.
- **`.agents/rules/tier2-router.md`:** Refuerzo de guardrails (anti-`self` en fases ligeras, guardrail de Modo Interactivo).
- **`docs/engram/index.md`:** Nuevos encabezados `## Session` y `## Release` añadidos al índice.
- **`funky-cli/src/commands/engram.js`:** Nuevas opciones en el prompt de Inquirer y el flag `--category`, más validación de categorías inválidas.
- **`funky-cli/src/commands/init.js`:** Scaffolding actualizado para crear los directorios `session/` y `release/` en nuevos proyectos.
- **`funky-cli/tests/engram.test.js`:** Nuevas aserciones para `session`, `release` y el error state de categoría inválida.
- **`funky-cli/tests/init.test.js`:** Conteos de directorios actualizados.

### 🔒 Guardrails Preservados
- Todas las categorías anteriores (`architecture`, `pattern`, `discovery`, `decision`, `bugfix`) siguen funcionando sin cambios.
- El parsing del `index.md` sigue siendo compatible con el formato de headers existente (`## Category`).
- La suite completa de 72 tests pasa en verde.

### 🧠 Aprendizajes (Engram)
- **`[invalid-category-validation]`:** Los comandos interactivos de CLI deben incluir siempre un error state para inputs fuera del enum válido; el happy path no es cobertura suficiente.
- **`[add-engram-categories-session]`:** Usar `self` en lugar de `define_subagent` en Tier 2 rompe el contrato de ligereza. El Modo Interactivo requiere pausas explícitas entre fases.
