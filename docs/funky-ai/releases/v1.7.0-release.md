# 🚀 Release v1.7.0 (Project Canvas)

## 🌟 Novedades

### Project Canvas Dinámico (`funky init`)
El comando `funky init` ha sido super-cargado. Ahora no solo inicializa los templates estáticos, sino que cuenta con dos modos:
- **Modo Interactivo:** Te guía con prompts amigables en la terminal para configurar tu Arquitectura, Estado, Base de Datos y APIs, generando automáticamente un archivo `PROJECT-CANVAS.md` en la raíz de tu proyecto.
- **Modo Headless:** Si ya tienes un `PROJECT-CANVAS.md` creado, `funky init` lo detecta y lo consume para inicializar el proyecto sin hacer preguntas, perfecto para automatización y clonación de setups.

## 🛠️ Mejoras y Refactors
- **TDD:** La lógica de generación dinámica del canvas está respaldada por Unit Tests (Vitest).
- **Integration Tests:** Nuevo test de integración verificando la persistencia física real en modo headless.
