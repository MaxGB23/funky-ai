# Release Notes: v1.3.0

- **Worker Handoff Canonizado:** Introducción del protocolo Worker Handoff oficial para estandarizar la delegación asíncrona de tareas a los agentes de ejecución.
- **Memory Polling:** Formalización de la lectura en `docs/engram/` (discoveries y bugfixes) al inicio de sesiones del Orquestador para emular la persistencia de contexto.
