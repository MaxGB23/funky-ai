# Release Notes: v1.4.0

- **Funky AI CLI Bootstrap:** Transición de operaciones manuales a scaffolding automatizado con el paquete `funky-cli`.
- **`funky init`:** Comando implementado para copiar el ecosistema global de reglas y engramas (`bootstrap/`) a nuevos repositorios de manera idempotente.
- **`funky phase <nombre>`:** Comando implementado para inyectar templates del ciclo Spec-Driven Development (SDD) directamente en el proyecto.
- **Templates Canonizados:** Materialización de templates para bootstrap y sdd, asegurando consistencia en todo el ciclo de vida del proyecto.
- **Smoke Test:** Verificación de flujos automatizados de CLI.
- **Plantilla Oficial Worker Handoff:** Estabilización de `docs/funky-ai/workers/plantilla-worker-handoff.md`.
