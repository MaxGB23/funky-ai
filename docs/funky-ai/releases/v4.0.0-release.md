# 🚀 Funky AI v4.0.0 Release Notes

## 🌟 Resumen de la Versión
MAJOR release del Movimiento 2 de **funky-forge**: el pipeline pasa de coordinar fases a **tener estado real y persistente**. `context.json` evoluciona a un **schema v2** con estado por fase (running/completed/failed/skipped), `currentPhase`, resultados con duración medida y warnings — y una **migración automática v1→v2 in-place** que conserva los proyectos existentes sin pasos manuales.

El orquestador `funky pipeline` ahora es una **máquina de estados**: reanuda corridas interrumpidas (una fase dejada en `running` se re-ejecuta, no se saltea), detiene el flujo si `assess` falla y emite **salida JSON determinista** (`status --json` / `all --json`) como un único objeto en stdout, con texto humano separado a stderr. `funky assess` y `funky estimate` devuelven objetos de resultado tipados y persisten el estado real; el flag `--context` queda como metadatos (sin escribir `dynamicQuestions`, que se renombra a `surfacedPatterns`).

### ✨ Nuevas Funcionalidades y Refactor
- **[Feature] Schema v2 de `context.json`:** Estado real por fase (`pending/running/completed/failed/skipped`), `currentPhase`, resultados con `durationMs` y warnings. Migración v1→v2 automática e in-place; versiones desconocidas rechazadas sin escritura.
- **[Feature] `funky pipeline` como máquina de estados:** Fases secuenciales assess → estimate, reanudación de corridas interrumpidas, fallo de assess marca estimate como `skipped` y detiene el pipeline con exit 1.
- **[Feature] Salida JSON determinista:** `pipeline status --json` y `all --json` emiten exactamente un objeto JSON en stdout (incluyendo el caso sin contexto: shape v2 not-started), con texto humano solo en stderr.
- **[Feature] Result objects en assess/estimate:** `{ phase, status, artifacts, durationMs, warnings }` retornados y persistidos vía `updatePhaseState`.
- **[Refactor] `--context` metadata-only:** `assess`/`estimate` escriben solo metadatos de estado (runAt, surfacedPatterns, phase state); el contenido de canvas siempre se lee del filesystem. `dynamicQuestions` renombrado a `surfacedPatterns`.
- **[Fix] Contratos de salida:** `--json` ya no contamina stdout con texto humano; `--context` faltante termina con exit 1 en assess/estimate.
- **[Docs] Specs y docs realineados:** Deltas R-P8..R-P12 aplicados en `openspec/specs/pipeline/spec.md` (R-P5 removida), R-A1 en `openspec/specs/assess/spec.md`, `docs/funky-forge/{pipeline,assess,estimate}.md` actualizados a v2.
