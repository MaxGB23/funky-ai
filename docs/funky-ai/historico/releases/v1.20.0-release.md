# 🚀 Funky AI v1.20.0 Release Notes

## 🌟 Resumen de la Versión

Esta versión introduce el **Tier 4 (Gentle SDD)** al ecosistema Funky AI, cerrando el ciclo de complejidad que empezó con la implementación del Auto-Tiering en la v1.19.0 (012). El Tier 4 es el modo "glass to break in case of emergency" del framework: un pipeline de 7 roles hiper-aislados donde cada agente tiene prohibido explícitamente salirse de su responsabilidad.

El nombre `funky gentle` es un tributo directo a **Gentle AI**, el framework que inspiró la arquitectura de sub-agentes descartables de Funky AI.

### ✨ Nuevas Funcionalidades

- **`funky gentle <feature>`:** Nuevo comando CLI que inicializa el scaffolding completo de Tier 4 en `docs/openspec/gentle/<name>/`. Genera los 7 templates de roles aislados (Explorer → Proposer → Spec Writer → Designer → Task Planner → Implementer → Verifier), cada uno con un `<system_prompt>` que bloquea al LLM de salirse de su responsabilidad.
- **Golden + Fallback pattern para Gentle:** Mismo patrón que `funky feature`: usa `.agents/templates/gentle/` si existe, cae back a `funky-cli/src/templates/gentle/`.
- **Sync ampliado:** `scripts/sync-templates.js` ahora sincroniza los 7 templates `gentle/` en el pretest. Cierra el gotcha `[cli-template-sync-drift]`.

### 🛠️ Archivos Modificados

- **`funky-cli/src/commands/gentle.js`:** Nuevo comando (clon estructural de `feature.js` con 3 diferencias: golden dir, destino, 7 archivos).
- **`funky-cli/bin/funky.js`:** Registro de `gentleCommand`.
- **`funky-cli/scripts/sync-templates.js`:** Sync ampliado para cubrir `gentle/`.
- **`funky-cli/src/templates/gentle/`:** 7 templates fallback con `<system_prompt>` por rol.
- **`.agents/templates/gentle/`:** 7 golden templates del workspace.
- **`funky-cli/tests/gentle.test.js`:** 4 tests unitarios (mirror de `feature.test.js`).
- **`funky-cli/tests/templates.test.js`:** Extendido con aserciones para los 7 templates `gentle/`.
- **`funky-cli/README.md`:** `funky gentle` agregado a la tabla de comandos.
- **`docs/funky-ai/guias/funky-ai.md`:** Tier 4 agregado a la tabla de Tiers y al árbol de decisión.
- **`docs/funky-ai/operaciones/guia-flujo-completo.md`:** Mapa de flujo y referencia rápida actualizados.
- **`.agents/rules/sdd-orchestrator.md`:** 2 mejoras: aclaración RFC vs explore.md (dimensiones ortogonales), fix doble lectura de template en `/sdd-ff`.

### 🔒 Guardrails Preservados

- El comando `funky feature` no fue modificado.
- El sistema de testing (11 suites, 39 tests) pasa al 100%.
- El patrón golden/fallback es idéntico al de `feature.js` — cero divergencia arquitectónica.

### 🧠 Aprendizajes (Engram)

- **`[silent-spec-skip]`:** `feature.js` lista `spec.md` en `filesToCopy` pero el template no existe → se saltea silenciosamente. Pendiente como feature separada.
- Regla actualizada en `sdd-orchestrator.md`: un RFC detallado NO reemplaza el `explore.md` — son dimensiones ortogonales.
- Fix `/sdd-ff`: leer `changes/{name}/tasks.md` en lugar del golden por separado (el `funky feature` ya lo inyectó).
