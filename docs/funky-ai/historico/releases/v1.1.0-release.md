# 🚀 Funky AI Protocol v1.1 - The *"Autonomous Memory"* Update

¡Llegó la actualización más grande a nuestra arquitectura Spec-Driven! En la **v1.1** atacamos directamente la fatiga cognitiva del Router Humano. Transformamos nuestros Sub-Agentes de "simples redactores" a **Entidades Autónomas** capaces de auto-gestionar su contexto y comunicarse como verdaderas APIs.  

A continuación, los cambios más potentes:

## ✨ Nuevos Features (Core Architecture)

- 🧠 **Memory Polling Dinámico (Zero-Prompt Context)**
  Se acabó la época de arrobar el `@post-mortem.md` manualmente. Introducimos una *Conditional Rule Topológica* (`engram-protocol.md`). Ahora, si el Worker detecta que está operando en un proyecto estructurado (presencia de `docs/`), **usa `grep_search` proactivamente** para husmear en el registro histórico antes de proponer cambios arquitectónicos.

- 🛠️ **Auto-Descubrimiento Pasivo de Skills**
  Le inyectamos el ADN de auditor a nuestro Perfil Global. Cualquier Agente instanciado tiene ahora la directiva estricta de buscar en `.agents/skills/` heurísticas estandarizadas para el tech-stack del proyecto (como el TDD RED-GREEN-REFACTOR) antes de escribir código a lo loco.

- ✉️ **API Verbal (The "Return Envelope")**
  Asesinamos el charlatanerío del LLM. Establecimos un bozal estructural. Cuando un Worker termina sus `.tasks`, está obligado a devolverle al Humano un sobre predecible y cerrado:
  ```yaml
  - status: [Done/Failed]
  - executive_summary: [Corto y al pie]
  - artifacts: [Archivos creados/tocados]
  - next_recommended: [El pase de pelota]
  - risks: [Warnings para el Orchestrator]
  ```

## 🛡️ Estabilidad & Safe-Contexting

- 🕵️ **Recuperación Estricta en 2-Pasos**
  Protegemos la ventana de contexto a muerte. Implicamos la regla industrial: *Paso 1: `grep_search` para rastrear IDs o líneas clave.* *Paso 2: Exclusivamente `view_file` en el target comprobado.* Se prohíbe la lectura ciega de archivos masivos.

- 🗃️ **Tipado de Memoria (Formato Estilo MCP)**
  Inspirados por las especificaciones robustas de esquemas de datos, nuestro Falso Engram (`docs/post-mortem.md`) dejó de ser un bloc de notas libre para convertirse en una base de datos NoSQL basada en texto. Toda nueva entrada asume estrictamente el formato: 
  `### [Type] Title` -> `**What:**` | `**Why:**` | `**Where:**` | `**Learned:**`.
