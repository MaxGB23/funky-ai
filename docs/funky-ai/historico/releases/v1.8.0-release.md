# 🚀 Funky AI v1.8.0 Release Notes

## 🌟 Resumen de la Versión
La versión **1.8.0** trae la **Auditoría de Sobrecarga Cognitiva (Cognitive Audit)**. Nos dimos cuenta de que los Workers estaban sufriendo de *"Lost in the Middle"*, omitiendo pasos clave como la generación de Handoffs y Checklists de Release porque las reglas globales tenían demasiada narrativa humana.

Esta release le pone una *Token Diet* estricta a todo el sistema, transformando la filosofía en reglas de Action Forcing inquebrantables. ¡Ahora los Workers ejecutan como verdaderas máquinas militares!

### ✨ Nuevas Funcionalidades y Refactor
- **Token Diet en Reglas Globales:** El archivo `.agents/rules/sdd-orchestrator.md` pasó de ser un cuento a un contrato. Las reglas ahora están en formato militar y encapsuladas en `<ROLE_ORCHESTRATOR>` y `<ROLE_WORKER>` con directivas `IGNORE` explícitas, bloqueando la contaminación de contexto.
- **Action Forcing en Templates:** En `tasks.md`, la fase de Release ahora vive dentro de un `<MANDATORY_RELEASE_PROTOCOL>`. El Worker está **obligado** a validar este checklist en su último bloque markdown, eliminando la posibilidad de que se saltee tareas críticas.
- **Sintaxis de Tools Corregida:** El `plantilla-worker-handoff.md` ya no utiliza pseudo-bash (`grep_search ...`) que causaba alucinaciones. Todo el Memory Polling usa directivas explícitas `ACTION: Execute ...`.

### 🐛 Bug Fixes
- **[stale-post-mortem-ref]:** Se eliminó una referencia fantasma a `docs/post-mortem.md` (un archivo deprecado desde la v1.2) que seguía viva en el Orchestrator, causando que el agente buscara memoria en un lugar vacío y perdiera aprendizajes.

### 🛠️ Doc-Ops / Deuda Técnica
- **Reducción del Engram Protocol:** Se depuró `.agents/rules/engram-protocol.md` para dejar puramente el schema MCP y los triggers. Menos charla, más persistencia.
- **Fix de Git Push:** Agregado el paso de `git push` a las instrucciones automáticas de Release para evitar inconsistencias locales/remotas.
