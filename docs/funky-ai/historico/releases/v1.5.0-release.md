# Release Notes: v1.5.0

**Fecha:** 2026-04-20
**Tipo:** Feature / Tech Debt

## 🚀 Novedades

### Enriquecimiento de Templates SDD
- Los templates generados por `funky phase` (`explore`, `proposal`, `tasks`, `worker-handoff`, `report`) dejaron de ser esqueletos vacíos.
- Ahora incluyen secciones completas, guías estructurales y referencias directas a las plantillas oficiales para asegurar que el protocolo de SDD y el Worker Handoff se ejecuten con máximo rigor.
- Se añadió la variable **Tier [N]** a los workers para manejar jerarquías de ejecución.

### README Oficial para el CLI
- Se creó el `README.md` en `funky-cli/` documentando exhaustivamente la instalación (vía `pnpm link --global`), requisitos y el uso de los comandos `funky init` y `funky phase`.

### Remediación de Deuda Técnica (Doc-Ops)
- Se generaron retroactivamente las release notes faltantes de `v1.3.0` y `v1.4.0`.
- Se actualizó el `ORCHESTRATOR-STATE.md` para reflejar el estado real del proyecto (v1.5, rama main).
- Se actualizó el `README.md` raíz apuntando al nuevo sistema de Engram (`docs/engram/`) y listando los features del CLI.
