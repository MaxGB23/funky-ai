# 🚀 Funky AI v1.13.0 Release Notes

## 🌟 Resumen de la Versión
Esta versión implementa la "Architecture Readiness v2", ampliando la evaluación arquitectónica para incorporar requerimientos no funcionales (NFRs) duros. Ahora el CLI es capaz de parsear campos como Compliance, Presupuesto, y Seniority del equipo directamente desde el markdown de arquitectura.

Se estableció que el pase de estos datos al prompt de revisión de IA es **obligatorio**, forzando al LLM a actuar como Abogado del Diablo incluso si no hay violaciones estáticas en las reglas.

### ✨ Nuevas Funcionalidades y Refactor
- **[Feature]:** Expansión del template `architecture-assessment.md` y `architecture-review-template.md` para inyectar NFRs.
- **[Refactor]:** Flujo del CLI actualizado en `assess.js` para que genere SIEMPRE el prompt de revisión arquitectónica AI.

### 🛠️ Archivos Modificados
- **`funky-cli/src/templates/sdd/architecture-assessment.md`:** (Agregada sección de NFRs)
- **`funky-cli/src/templates/sdd/architecture-review-template.md`:** (Prompt extendido)
- **`funky-cli/src/commands/assess.js`:** (Refactor principal)
- **`funky-cli/test/assess.test.js`:** (Tests actualizados para frontmatter)

### 🔒 Guardrails Preservados
- Flujo de Two-Stage Memory Polling intacto.
- SDD Docs intactos.

### 🧠 Aprendizajes (Engram)
- **`[architecture-readiness]`:** El TDD de parseo de Markdown asegura que el CLI siempre respete la estructura del frontmatter antes de intentar pasarlo a la IA, asegurando alta cohesión.
