# 🚀 Funky AI v1.19.0 Release Notes

## 🌟 Resumen de la Versión
Esta versión introduce el nuevo comando `funky estimate` (RFC 002: Project Cost & Pricing Estimator). El objetivo de esta feature es proveer una herramienta interactiva en CLI para calcular un piso base orientativo de presupuesto para un proyecto de desarrollo, cruzando factores técnicos arquitectónicos extraídos directamente de los Canvas (`PROJECT-CANVAS.md`, `INFRA-CANVAS.md`) con factores de negocio aportados por el usuario (región, tamaño de la empresa, urgencia).

Adicionalmente, la herramienta genera de forma persistente un reporte en Markdown (`docs/pricing-analysis.md`) que no solo registra el cálculo, sino que también inyecta un prompt de mentoría en la IA (Value-Based Pricing) para ayudar al usuario a definir el precio final a cobrar, más allá de la estimación de horas.

### ✨ Nuevas Funcionalidades y Refactor
- **Comando `funky estimate`:** Analiza la arquitectura local, interactúa con el usuario mediante prompts, calcula la complejidad y el riesgo, y emite un veredicto de piso base.
- **Artefacto `pricing-analysis.md`:** Generado dinámicamente como registro histórico y prompt puente para la negociación de precio basada en valor.

### 🛠️ Archivos Modificados
- **`funky-cli/src/commands/estimate.js`:** Nueva lógica de extracción, uso de `@inquirer/prompts` y generación de markdown.
- **`funky-cli/package.json`:** Agregada dependencia `@inquirer/prompts` y versión bumpada a 1.19.0.
- **`funky-cli/README.md`:** Tabla de comandos actualizada.
- **`docs/funky-ai/operaciones/guia-flujo-completo.md`:** Nueva etapa 1.5 opcional añadida al flujo end-to-end.

### 🔒 Guardrails Preservados
- La lógica de extracción es agnóstica y no emite requests externos.
- `funky estimate` se integra de forma opcional al ciclo de vida existente sin alterar el flujo SDD core.

### 🧠 Aprendizajes (Engram)
- **`[inquirer-integration]`:** El uso de Inquirer en CLIs interactivos permite bifurcar la ejecución entre operaciones headles y guiadas (aunque aquí fue una adición directa de prompts interactivos).
