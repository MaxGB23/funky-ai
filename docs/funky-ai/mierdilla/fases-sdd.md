
che, cuáles son todas las fases sdd que manejas

Che, las fases de Spec-Driven Development (SDD) que manejo como orchestrator son estas, loco:

Explore: Investigar y clarificar ideas antes de comprometerse con un cambio.
Propose: Crear una propuesta con intención, alcance y enfoque.
Spec: Escribir especificaciones con requerimientos y escenarios (delta specs para cambios).
Design: Crear el documento técnico con decisiones de arquitectura y enfoque.
Tasks: Desglosar el cambio en una lista de tareas de implementación.
Apply: Implementar las tareas, escribiendo el código real siguiendo las specs y el design.
Verify: Validar que la implementación coincida con las specs, design y tasks.
Archive: Sincronizar las delta specs con las main specs y archivar el cambio completado.
