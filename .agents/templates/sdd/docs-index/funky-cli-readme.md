# Índice de Secciones: `funky-cli/README.md`

- **1. ¿Qué es Funky AI CLI?:** Responsabilidad de scaffolding y estandarización del ecosistema SDD.
- **2. Prerequisitos:** Node.js v22.12+, pnpm y `pnpm setup` para el uso global.
- **3. Instalación:** Clonado, `pnpm install` y `pnpm link --global`.
- **4. Comandos:** Tabla de comandos disponibles (`init`, `scaffold`, `assess`, `estimate`, `pipeline`, `feature`, `engram add`, `skills`).
- **5. Templates SDD Disponibles:** Tabla de templates inyectables (`explore`, `proposal`, `spec`, `tasks`, `report`, `release-checklist`/`release-notes`, `docs`).
- **6. Estructura generada por `funky init` y `funky scaffold`:** Árbol estandarizado de directorios resultante post-init + post-scaffold.
